# Code of Conduct

We want CrawlBouncer to be a friendly place for everyone, whatever their experience level.

**Do:** be kind, be patient with beginners, give constructive feedback, assume good intentions, and credit other people's work.

**Don't:** insult or harass anyone, post other people's private information, or use discriminatory language or jokes.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders.
To report a problem, contact the maintainers through a private GitHub security advisory or the contact method on the maintainer's GitHub profile.

This text is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
